# Web Scraping with BeautifulSoup and Scrapy

Two reports that present web data extraction in Python with two common approaches.

| File | Content |
|---|---|
| `wez-scraping-BeautifulSoup.pdf` | Report on web scraping with **BeautifulSoup** |
| `wez-scraping-scrapy.pdf` | Report on web scraping with the **Scrapy** framework |

## BeautifulSoup vs. Scrapy at a glance

| | BeautifulSoup | Scrapy |
|---|---|---|
| Best for | Small scripts, a few pages | Large crawls, many pages |
| Learning curve | Easy | Medium |
| Speed | Sequential by default | Asynchronous, fast |
| Built-in export | No | Yes (JSON, CSV) |

## Tech stack

Python · BeautifulSoup · Scrapy
